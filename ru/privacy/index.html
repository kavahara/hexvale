Сайт

На сайте нет cookie, аналитики, рекламы и отслеживания, он не загружает сторонние скрипты и шрифты.

Сайт размещён на GitHub Pages. При посещении GitHub записывает ваш IP-адрес в целях безопасности — подробнее в заявлении GitHub о конфиденциальности (на английском). Мы не получаем эти журналы и не пользуемся ими.

Письма

Если вы напишете нам, мы получим ваш адрес и текст письма. Мы используем их только для ответа и помощи с вашим вопросом, не продаём и никому не передаём. В любой момент можно попросить удалить переписку.

Наши приложения

У каждого приложения своя политика, где точно описано, что оно делает с данными:

  • Orlo — не собирает данные.

У фитнес-приложения будет своя политика конфиденциальности до выхода.

Изменения политики
